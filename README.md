# jasonmiazga.com

Jason Miazga's personal site and blog, built with [Astro](https://astro.build) and deployed on Netlify (`netlify.toml`).

- `npm install`, then `npm run dev` for a local server, `npm run build` to build into `dist/`.
- Blog posts are Markdown in `content/blog/`; each is served at `/<file-name>/`.
- `static/` is copied as-is. `static/agent/` holds the family assistant's about page and privacy
  policy, which Google's sign-in screen links to, so keep those URLs.
